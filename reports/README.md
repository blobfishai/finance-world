# reports/

- `summary.json` — flake-scan matrix: per model x task, trial rewards + class
  (solidPass / flaky / solidFail).
- `failure-report-<model>.md` — per-model analysis generated by `sim/build_reports.py`:
  class table, per-task failure modes (submitted_blind, wrong_value, missed_system,
  missing_field_or_no_submit, tool_errors, budget_exhausted, agent_error), call paths of
  failing trials, final-message excerpts, and calibration suggestions per the house triage
  rule (fail 3/3 → too_hard after audit-before-blame · mixed → flaky = the frontier, keep ·
  pass all → too_easy, escalate).

Never hand-edit; regenerate from traces.
